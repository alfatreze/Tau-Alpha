## Notes

- **rect**: The base primitive every meter uses.
- **bar**: VIZ_BARS is the cost baseline: 36 commands.
- **sblit**: Chladni draws its plane with one scaled blit; the source must be written through the SDRAM mailbox, never a raw pointer (B-192).
- **cblit**: Meter previews and cover art use it.
- **rrect**: Timing closed in a fit (B-235) but not yet run on a Pocket.
- **hw_spectrum**: Gates meters through meter_afford()'s caller list (needs_hw_spec).
- **hw_wave**: The capture is proven; the per-column draw path is compiled out since B-302 until it is batched, so a meter must not rely on it.
- **sdram_plane**: Only via the mailbox; raw 0xA0000000 pointers hang (B-192).
- **vsync_beam**: Owned by the host; a module never gates itself.
- **stereo**: Per-channel history for waveform presets does not exist yet.
- **alpha_blend**: Never closed timing (-2.97 ns, B-243). Rejected for any selectable meter.
- **blit_flip**: Wanted by Chladni mirror tiling.
- **row_burst_sblit**: Chladni cost lever.
- **index_plane_math**: Chladni sand mode.
- **beat_detect**: docs/HARDWARE_METER_IDEAS.md item 1.
