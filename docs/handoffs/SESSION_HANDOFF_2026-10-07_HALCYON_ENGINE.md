## The first hardware result and what it found (B-649, B-650)
Owner on 107: every non-FLAT Halcyon setting sounds like "fluttering wings"/static; HW GAIN toggle OFF pops (by design); 16-bit output "only lower volume" (direction not stated; expected ON = +6 dB louder); a pop on the first repeat of a track (unexplained). Findings (simulation only, not yet measured on hardware): (1) the engines' sample tick was an integer divider, 48,030.7 Hz at 66.667 MHz (30.7 Hz beat); (2) the I2S writer (`sound_i2s.v`) pushes on ANY output change and the engines updated left and right ~100 clocks apart: every sample made two output updates and ~7% of frames carried a **torn stereo pair** (probably the dominant audible error). Both fixed in `tau_halcyon.sv` and the shipped `eq_biquad.v` (fractional accumulator; `pair_l/pair_r` latched in one clock); `sim/tb_halcyon_tick.v` checks 4,800 ticks and 0 torn pairs with mutants BUG 11/12. **The old preset EQ on every shipped core has both faults at 66.667 MHz (inferred, unmeasured).** The new build must be listened to again; Info > I2S JITTER (needs `TAU_I2S_DIAG`, in the b650 bundle) should read about 1,389 cycles per update, about 700 if pairs are still torn. A free control test on the current card: cycle the old EQ (Y) on a 1 kHz tone on 107; it should flutter too.

## Traps found this session
- **zsh:** `$VAR` with spaces is not word-split (use arrays or inline), `echo "====="` fails (`=` expansion), `sed -i` needs `''` on macOS.
- Icarus: declare-before-use for a net used in a `wire` expression; control pulses in a testbench must be non-blocking; `-D` strings need `'-DX="..."'`.
- `check_heap_gap.py --update` after any hot-RAM change; the diagnostic gap is 1.4 KB (tempo on): any new hot code can break the 192 KB link.
- A card that was ejected shows `Pock` again at once; `install_dev_core.py --assets FILE` replaces the carried `tau-assets.bin`; the profile variant does not fit with Halcyon+tempo.
- The cold-calls check prints a spurious warning if the last-built ELF is the release one; run it after `check_heap_gap.py`.
- Never touch the owner's `TAU_DEV_BARCODE_04`, `TAU_DEV_METER_14/18`.
