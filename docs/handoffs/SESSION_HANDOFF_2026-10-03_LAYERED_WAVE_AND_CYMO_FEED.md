## Traps learned (also in the skill: KB-085, KB-086, KB-087, all local)
- Never `--build-flags` with spaces; never build a flagged firmware and then run `check_heap_gap.py` before packaging (it rebuilds the same output path): `package_dev_build.py --build-flags` builds as its last step.
- `fb_fence()` gives up after ~50 ms; the compose uses `helios_drain()` (retries) and must not switch `R_DBUF_CPU` back before it returns 1.
- Host harnesses stub the Helios globals (`hs_base`, `helios_*`); a new helper used by `fw/chladni.inc` or `fw/layered_wave.inc` needs a stub in `sim/chladni_module_harness.c`, `sim/test_helios_clip.py`, `sim/test_helios_beam.py` or `make test-host` fails to compile.
- This project's shared checkout: check `git branch --show-current` right before every commit; use a worktree for anything long (this session used `../tau-alpha-lw-flicker`, removed after the merge).
