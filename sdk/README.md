# sdk/: the meter SDK, inside the Tau Alpha repository

Three trees that are exported into two separate public repositories (the template travels inside the SDK repository, as `template/`) by `tools/export_sdk.py` (nothing is pushed or created by this repository):

| Tree | Becomes | What |
|---|---|---|
| `sdk/sdk/` (+ `sdk/docs/`) | `tau-alpha-meter-sdk` | the header, the build driver, the conformance suite, the documents |
| `sdk/template/` | `tau-alpha-meter-sdk/template/` | a minimal working meter for authors outside this repository: copy it to start |
| `sdk/meters/` | `tau-alpha-meters` | the seven shipped meters as SDK projects (regenerated by `tools/sdk_collect_meters.py`) |

`tools/player2/new_meter.py` is the scaffolder for meters **inside** this repository; the template is for everyone else. Tests: `sim/test_sdk_conformance.py` (the suite, its 30 broken-meter fixtures, 19 mutants), `sim/test_sdk_toolchain.py` (clang against the project's gcc on the seven meters), `sim/test_sdk_sync.py` (headers, vendored files, documents), `sim/test_sdk_export.py` (the export builds the template from the exported tree alone).
