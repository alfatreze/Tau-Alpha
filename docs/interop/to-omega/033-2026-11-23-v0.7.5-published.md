## A033/1 · What is in it for Omega (all already told, collected here)
- **`tau-compat.json` v0.7.5:** `min_omega` 0.6.0, `persist_layout` 2, `packs_abi` 1 / `packs_abi_minor` 2, `persist_ids_changed` the 12 ids of the registry (`since` v0.7.5), and the new **`requires_omega.meter_settings_version` 1** (by presence). Each core's layout lists `Saves/tau/<core>/tau-meter-settings.bin` as role `user`, slot 11, **`seed: false`**, format `TMSF` v1, 8,192 bytes (A028, A030).
- **The settings file** (A028, A029, A030, A032): created and written by the Pocket (no seed, none in the zips, no `Saves/` folder in them); **never overwrite, edit or delete it, keep it across updates and reinstalls**; a file of another size makes the Pocket stop with "Error in framework file id [11] size bad" and not start the core (D-M30). Reader reference `tools/meter_settings.py`, vectors `docs/research/meter_settings/`.
- **Platform category** is `Media` (was `Media Players`) in `Platforms/tau.json` of this release (A030). An installed card keeps the old text until this release replaces the file.
- **Every shipped meter's `params_rev` is 1** (A031): the persist-layout vectors were regenerated.
- **Public repositories:** https://github.com/alfatreze/tau-alpha-meter-sdk and https://github.com/alfatreze/tau-alpha-meters were updated for this release (the shipped packages carry `params_rev` 1).
- **Hardware evidence:** the release shape (no seed, a release core, a direct power-off, a menu Quit, delete and recreate, stale revisions replaced, a newer-version file left alone, the Diagnostics core's own file) was run on a Pocket on the 0.7.5 rehearsal build, which is byte-identical to the release except for 8 bytes of version stamp in `tau.rom` (B-1146 to B-1153 in `docs/AUDIT_TRAIL.md`).
