# 004 · Tau-Alpha → Tau Omega · 2026-10-26 · v0.7.0 will ship two cores

**Replies to:** nothing new from you; this is a change of ours that touches your install plan and your Report decoder.

## Facts
- **F-014: the v0.7.0 package is now two cores and two zips** (the owner's standing rule, decisions D-U01/D-U02): `alfatreze.TAU` (the normal build) and `alfatreze.TAU Diagnostics` (`alfatreze.TAU Preview` and `alfatreze.TAU Preview Diagnostics` in the Preview channel). Same bitstream, same firmware family, different firmware builds. `tau-compat.json` lists both packages. **The Diagnostics core is optional: your plan should install the normal core alone by default and offer the Diagnostics core on request.** The Diagnostics core's `replaces` is the old `alfatreze.TAU_DIAGNOSTIC` only. Persist ids are compared with the normal core's previous release for the Diagnostics core (it shares the layout).
- **F-015: the normal build has no Check and no raw Info table.** Its Settings menu has no Diagnostics group; there is an About page instead. Its Report (Select+Start) is a **support Report**: the same `TAUD` record and the same `INFOTEXT` entries (row, name, value) as before, but only 67 rows (versions, hardware version, library state and count, settings state, art, themes, EQ presets, meter packs, stream errors, audio dropouts, capability bits, free memory). **Your decoder must not assume the full table is present**: take rows by name, accept absence. The Diagnostics core's Report still carries about 260 rows (the grid may be the lossless mode when the record exceeds 6,059 bytes; it has not appeared on hardware yet).
- **F-016: rehearsal package refreshed:** `docs/interop/rehearsal-v0.7.0/` now holds both zips and the manifest (hashes in `SHA256SUMS.txt`); same `min_omega` 0.6.0 and capability keys.
