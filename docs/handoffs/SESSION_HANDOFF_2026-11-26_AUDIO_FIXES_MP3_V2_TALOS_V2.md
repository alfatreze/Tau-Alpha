## Routine that worked (and its traps)
- **Merging agent branches:** merge in a scratch worktree (`git worktree add -b merge-verifyN .claude/worktrees/merge-verifyN main`), resolve `docs/AUDIT_TRAIL.md` (and sometimes `Makefile`) conflicts by KEEPING BOTH SIDES, run the new tests, the link gate, build `fw2/build.sh` DIAG=0 and DIAG=1 against main's `tau.rom` hashes, then the full `make test-host` (30 to 50 minutes) in the background, then merge into `main` (fast-forward if the branch contains main). Commit as the owner with NO AI trailer; push only on the owner's "push main".
- **Traps hit:** `grep -c` exits 1 when the count is 0, so never chain it with `&&` (a merge commit was silently skipped once); finish and commit one merge before starting the next; zsh treats `$c:r` as a modifier (use `${c}`); the repo path has a space, quote everything; host C tests link only with `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk` (skill KB-260); the 5-hour usage limit stops agents mid-task (resume with SendMessage, their work is saved in their worktrees); a subagent saying "done" is not proof: check its branch and gates; never say something was sent before the call is made; check licences against the real LICENSE files (the session once wrote Gallery as MIT; it is Apache-2.0).
- **Clean-room process:** the model author worked in a scratch tree with only the allow-listed files, by instruction (honour-based: the tool cannot restrict file access); the RTL author needs a stronger separation.
- **VM:** the x86 VM (`ssh -i ~/.ssh/taualpha_vm_ed25519 -p 2222 taualpha@127.0.0.1`) is shared with other projects (another compile ran during the probes) and hung once under load (restart is the owner's, in UTM). Map-only probes take 3 to 4.5 minutes each.
