# Cymo C3: the output stage (spec, 2026-10-06)

**Status: DESIGN + HOST MODEL. Nothing in RTL or firmware yet.** Parent plan: `CYMO_AUDIO_ENGINE.md` section 6.2 and phase C3. Model: `tools/lab/cymo_out_model.py`, properties proven by `sim/test_cymo_out_model.py` (in `make test-host`).

## 1. The chain today (read from the RTL and firmware)

decoder (software) -> **firmware gain** (dB volume with ramp, ReplayGain folded in, discontinuity fade; `>> 15`, truncating) -> `pcm_fifo` -> [Cymo resampler, 44.1 kHz only] -> `eq_biquad` (Q20.16 state, **clamps to 16 bit**; preset 0 is a bit-exact bypass) -> `sound_i2s` (**drops the LSB: 15-bit slot**, F2). Three weaknesses a post-EQ stage can fix without touching the decoders: (a) the EQ hard-clamps a boosted peak (square-wave distortion), (b) the final 16-to-15-bit step is a plain floor (biased by half an LSB, error correlated with a quiet signal), (c) volume sits in front of the EQ so an EQ boost on a loud track has no headroom.

## 2. First slice (recommended): post-EQ soft clipper and dither, firmware untouched

1. **Soft clipper.** `eq_biquad` hands over its result *unclamped* as a signed 18-bit word (+-4 full scale; the 36-bit state already holds it, so this only moves where the clamp happens). Up to the knee (0.9 FS = 29491) the output equals the input exactly; above it a 256-segment piecewise-linear table (128-unit segments) approximates `KNEE + H(1 - exp(-(|x|-KNEE)/H))`, `H = 32767 - KNEE`: slope 1 at the knee, never beyond 32767, monotonic, odd-symmetric. Model: worst error against the ideal curve 1.33 LSB at 16 bit (below the 15-bit slot's own 2-unit step); step at the knee 1 LSB; a +3 dB peak (46341) comes out at a rounded value inside full scale. **CORRECTED by the review (section 6, finding A): the earlier claim that the clipper is transparent with the EQ off was wrong** (the knee is 0.9 FS, so any loud master with samples above 29491 would be altered). The clipper must be bypassed bit-exactly when the EQ preset is 0 (or the knee moved to full scale).
2. **TPDF dither + rounding into the 15-bit slot.** `y15 = (y + d + 1) >> 1`, `d` in {-1, 0, +1} (probability 1/4, 1/2, 1/4, mean 0, variance 0.5, from two bits of a 32-bit LFSR). The `+1` removes the floor's half-LSB bias (model: -1.08 to +0.04 16-bit LSB). On a quiet 3-LSB tone the harmonic distortion drops from -15.6 to -24.2 dB re the fundamental; silence in gives only 0 or 1 at the 15-bit output. A macro keeps the plain-truncation path for the A/B.
3. **Cost [EST]:** the table is 257 x 16 bit (MLAB or ROM), one 17x10-bit interpolation multiply (a DSP block or shift-add), a 32-bit LFSR and a few adders: well under 100 ALMs and at most one DSP. Must be re-checked against the current macro set (the 98% ALM level, B-378) before the fit.
4. **Where it sits:** between `eq_biquad` and `audio_l/audio_r` in `mp3_soc.v`, one pipeline stage per operation (project timing rule), registered output. Behind a macro (`TAU_CYMO_OUT`) and a sticky enable register (default OFF until firmware probes it, the same probe-then-adopt rule as every RTL unit here), so a bitstream with the unit and firmware that does not know it is bit-identical to today.

## 3. Second slice (after the first is on a Pocket): gain and ReplayGain in RTL

Move volume (log taper, 5 ms ramp), ReplayGain and the discontinuity fade out of the firmware sample loops into a register-driven gain stage placed **before** the EQ (so an EQ boost can use the soft clipper) or after it, per the owner's choice (section 5, decision 2). Firmware then stops touching samples at all: the burst push and `cymo_push()` shrink, the CPU saves the multiply per sample, and one mechanism serves music and tempo. Larger change (every audio path, every build), so it waits for the measured result of slice 1. A 24-bit input path for FLAC (no truncation before volume and EQ) belongs with this slice.

## 4. Test plan

- Host (done): model properties in `sim/test_cymo_out_model.py` (transparent below the knee for every value, monotonic over the 18-bit range, never above 32767, odd symmetry, error and knee continuity, dither mean/variance/shape, harmonic reduction, no DC bias, silence bound).
- Golden vectors from the model, testbench replaying them bit-exact, mutants for: knee off by one, table slope wrong, no `+1`, dither always 0, LFSR taps wrong, sign handling.
- Fit on two seeds against the current macro bundle; then a hardware A/B (stage OFF vs ON) with the loopback tool (`tools/lab/cymo_loopback.py`): a -6 dBFS tone must be identical, a hot EQ preset on a loud track must show less distortion, quiet passages and fades must show lower harmonic content. Listening pass by the owner.
- ReplayGain is tested in the same session on the same build (owner, 2026-10-06): a few tagged tracks, Off/Track/Album, Info row and level; its persist-range fix (B-600) has never been heard.

## 5. Decisions for the owner

1. First slice as above (soft clipper + dither after the EQ, firmware untouched)? Recommended.
2. Gain stage position in slice 2: before the EQ (headroom for boosts, soft clipper catches the rest) or after it (volume independent of EQ)?
3. F2 (16-bit slot instead of 15) A/B behind a macro, folded into this fit so there is only one bitstream to test?
4. Dither always on, or a Settings switch (some listeners compare)? Suggested: a Diagnostics-only switch for the A/B, always on in release if it wins.

## 6. Engineering review (2026-10-06, embedded-audio view, Pocket constraints, `analogue-pocket-dev` skill)

Verified against `sound_i2s.v`, `eq_biquad.v`, `tau_cymo_resamp.sv`, `tools/eq_model.py`, the skill's audio reference and the project's resource ledger. **Verdict: sound direction, wrong first slice.** The clipper is worth keeping (with a fix); the dither as specified treats a symptom of the 15-bit slot and should wait for the F2 decision.

### Revised plan

1. **Now, firmware only:** rounding term in `pcm_gain_apply` (and the fade) with a host test (bias removed, SNR improved at volume 65); same for the resampler's `>>> 15` later (RTL, with slice 2).
2. **F2 A/B** (macro, one small fit or a shared fit): measure level, headroom, THD; decide 15 vs 16 bit. ReplayGain test rides on the same build.
3. **Clipper (fixed, EQ-bypass bit-exact, M10K + DSP, atomic L/R)** with the model's golden vectors, testbench and mutants; fit; hardware A/B on a boosting preset at volume 100.
4. **Slice 2: the gain stage in RTL** with a wide internal word, ReplayGain/volume/fade, one TPDF dither (two-bit draws, per-channel, silence-gated) at the final 16-bit quantisation, resampler clamp replaced by the same soft limiter; firmware stops touching samples.
5. Open owner decisions from section 5 stand, with decision 3 (F2) now **first**, not last.
