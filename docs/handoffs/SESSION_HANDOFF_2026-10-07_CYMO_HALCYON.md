## Measured facts worth keeping (all in the docs above)
18-bit Q2.16 EQ coefficients are too coarse at 100/220 Hz (0.27-0.61 dB error, non-monotonic Bass steps; 24-bit fixes it: 0.016 dB). Bilinear cramping up to 1.14 dB at 10 kHz. Trapezoidal SVF with 18-bit coefficients is about 60x less sensitive than DF1 at LF; rounding noise negligible for both. A fixed parallel band-pass bank cannot replace the cascade (0.4-1.9 dB presets, up to 4.4 dB single bands). Shipped bitstream: ALM 71% (13,207/18,480; the old "98%" was the pre-T2-00 fit), M10K 256/308, DSP 20/66, PLL 2/4, pins 224/224, worst hold +0.14 ns. Hardware serializer sends `{sign, audio[15:1]}`: 15 bits, 6 dB down (F2, A/B pending).

## Working notes and traps
- Firmware builds need `RISCV_TOOLCHAIN_BIN="$PWD/toolchain/xpack-riscv-none-elf-gcc-15.2.0-1/bin"`; package with `tools/package_dev_build.py --number NNN --variant diagnostic --build-flags "RAM_192K=1,CLK66=1,SDRAM_BUSY=1,LPC_FW=1" [--rbf raw.rbf --rbf-sha256 H]` (flags comma-separated; the tool builds last, pairing gate on); install with `tools/install_dev_core.py <pkg> --carry-from CORE --remove CORE --yes` (dry run is default). Pixel grid (`TPG`) is now default ON in `fw/build.sh`.
- `make test-rtl` takes several minutes (run it in the background); its output contains deliberate `FAIL` lines from the PSRAM fault-injection runs: the exit code and the final `PASSED` lines are what count. `make rtl-lint` prints pre-existing width warnings in `mp3_fb.sv` and exits 0.
- zsh does not word-split unquoted variables (use functions, not `set -- $pair`); `sed -i` needs `''` on macOS and breaks on `/` in patterns (use Python for edits).
- Figma: the file's design pages have no connector API (`createConnector` missing, no connectors to clone); `use_figma` frames may carry vertical auto layout that silently re-places children: set `layoutMode='NONE'` first. Fonts Geist / Geist Mono.
