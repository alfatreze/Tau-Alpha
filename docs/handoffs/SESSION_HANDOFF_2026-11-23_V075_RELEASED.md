## Things that bit this session (so they do not bite again)
- **Read the knowledge base before writing a protocol model** (KB-008 already said reads are buffered by one word; the spec was first written backwards).
- **After launching a fit of a changed memory, look at Analysis & Synthesis within 5 minutes** (a port with two addresses fails there, KB-256).
- **A stale user bin on a card overrides the core's own bin** (`meter_bin.py info` the file before trusting a settings test).
- **zsh does not word-split unquoted variables**; a regex that rewrote audit ids also hit `KB-0xx` (use `\b`).
- **The permission classifier blocks git commit and push in a folder outside the session's project** until the folder is added (`mcp__ccd_directory__request_directory`) and the owner says push; the owner's standing words are "push main" for this repo, explicit approval per push elsewhere.
- Commit as the owner, no AI trailer (rule 9). The Pocket Sync plugin and the SDK repos live in clones (`work/sdk-pub`, `work/meters-pub`) or their own folder (`DEV PROJECTS/tau-alpha-pocket-sync`).
