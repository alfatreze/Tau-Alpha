# v0.7.5: an update-flow test for Tau Omega (the release is published; this is a test sheet, not a rehearsal package)

For v0.7.0 we handed Omega a throwaway release to rehearse with. v0.7.5 is already published, so Omega tests with the **real** assets: https://github.com/alfatreze/Tau-Alpha/releases/tag/v0.7.5 (`alfatreze.TAU_0.7.5_2026-11-23.zip` SHA-256 `0cd242ad9ec7de5ebfbe48a77407a5d9f03d0f50e86ec8f9c396702cb101cb53`, `alfatreze.TAU_Diagnostics_0.7.5_2026-11-23.zip` `5f5fd0000d28ef5f9210c007a717343dbb0d4d5aabbfb7eb311999823762c9c6`, `tau-compat.json` `5a8edac594d223b74c16f1fe39ff5be50dcefe87c107c4be7b169a5b29ffbd94`). The settings fixtures below are **referenced, not copied** (they live in `docs/research/meter_settings/`, generated by `tools/meter_settings_vectors.py`; SHA-256 from `expected.json`). Work on a COPY of a card, never a real one.

Each case is a card state, what Omega does, and what must be true afterwards. The settings file is `Saves/tau/alfatreze.TAU/tau-meter-settings.bin` (the Diagnostics core: `Saves/tau/alfatreze.TAU Diagnostics/...`).

|---|---|---|---|
| 1 | TAU 0.7.1, **no** settings file | updates to 0.7.5 | `Cores/alfatreze.TAU/core.json` says 0.7.5; **no `Saves/` file created** by Omega; `Platforms/tau.json` category is `Media` (was `Media Players`) |
