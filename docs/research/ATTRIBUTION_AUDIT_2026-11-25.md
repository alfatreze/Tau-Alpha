# Attribution audit: every upstream item the repository ships, vendors, links or derives from (2026-11-25)

**Evidence label: HOST-ONLY.** Static reading of the repository at `63bbf0c9` (branch `worktree-agent-a84e5f94025f4c4d5`, from `main`) and of public upstream pages through the GitHub API (licence files, headers and file hashes; nothing about this repository or its owner was sent anywhere). Nothing was built, fitted or run on a Pocket. **This is a fact list for owner decision D-T20 item 5. It draws no legal conclusion**: where a licence "interacts" with MIT, that is an open question (see `ATTRIBUTION_OPEN_QUESTIONS_2026-11-25.md`), not an answer.

How to read the "Licence as stated by the project" column: the text of the project's own licence file or file header, as fetched or read on 2026-11-25. "Verified" means the file was fetched and read (or hashed against the repository's copy). "Not verified" means it was not found or not read.

Ships in a release: **core zip** = the Pocket core zips (`tools/make_release.py`: `Cores/`, `Platforms/`, `Assets/` only, i.e. `bitstream.rbf_r`, `tau.rom`, `tau-cold.bin`, images, JSON); **packs** = meter packs; **SDK** = `tools/export_sdk.py` output; **lab** = `tools/make_lab_drop.py`; **tools** = repository tooling only.
Not in any zip: the release zips contain no `LICENSE`, `NOTICE.md` or third-party licence text (the only text file in `dist/Cores/alfatreze.TAU/` is `README.txt`, which does not mention licences). See finding F1.
