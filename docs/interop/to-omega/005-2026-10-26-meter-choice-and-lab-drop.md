- **Q-019: yes, Omega may build `TPKB` bundles.** The rules to implement and test against are in the format file (`docs/features/TAU_PACKS_FORMAT.md`) and its independent reader `tools/tau_assets.py parse_packs`: packs back to back in slot order, `meter id` = slot = the registry index, each pack's `origin` = `0x24900000 + slot * 0x10000`, `abi` major 1 and minor not above 2, a pack for another slot refused, no outer checksum, the file length equals the sum of headers and images. There is no `pack_bundle.py`; the writer is `tools/player2/build_packs.py`. **The pack library** (one `.tmpk` per meter with a manifest of key, id, slot, ABI, SHA-256 and size) as a release asset is accepted in principle; it does not exist yet and is ours to build (we will announce it with an id).
- **Q-020: limits.** `MTR_PACK_SLOTS` = 8 slots, each pack's image must fit its PSRAM slot of `0x10000` (64 KB) including `.data` initial values and the descriptor; so a bundle holds at most 8 packs (Winamp Bars is built in, so seven extra meters at most). The 65,536-byte assets read limit applies to `tau-assets.bin` (`THEM`, `PRST`, `METR`, `MPKB`) read at boot; `tau-packs.bin` is read through its own data slot (9). We have not measured a hard size cap for the slot-9 file beyond the 8 x 64 KB structure (about 0.5 MB); treat 8 packs as the limit. All five packs are about 28 KB today.
- **Q-021: yes, scheduled (D-O03).** `METR` entries carry `flags` and `order`; the firmware parses and ignores them today. We will apply hide and reorder in `fw2` (host-tested). Not in v0.7.0 unless the owner adds it; do not write non-default values expecting an effect before we say it is built.
- **Q-022: confirmed.** `METR` always wins over a pack's own presets and over a built-in meter's: it replaces the meter's whole preset set (1 to 8 presets, default inside the set). A user preset cannot be added to a pack's list by `METR`; to add one, write the full set (our presets plus yours). An entry that does not fit (unknown id, newer schema, different parameter count) is skipped alone.
