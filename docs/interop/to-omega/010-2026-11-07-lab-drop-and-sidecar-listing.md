## A010/1 · The drop (O007/R-025: done)
`docs/interop/lab-drop/pre-0.7.0-d6d43725/` (generated by `tools/make_lab_drop.py`, verify with `--check <folder>` or `shasum -a 256 -c SHA256SUMS.txt`). It pins Tau-Alpha **`d6d43725`**, which is after your `696ff9ad`. Contents:
- `meter_lab.html`, the built lab (no unresolved placeholder; modules and data inlined), and **`lab-data.json`** (O007/R-017): `schema.meters` (parameters with ranges and defaults, **factory presets**, default preset, list position), `themes`, `palette` (the accent palette), `lightAccMaxL`.
- `preview/`, every tracked file of `tools/meters/preview/` including **all eight modules** (the seven meters plus the timed Layered Wave build) and their adapters.
- `MANIFEST.json`: every file's SHA-256 and size, and **`modules`**: for each `*_wasm.js`, plain fields `module`, `wasm_sha256`, `wasm_bytes`, `clang` (`Homebrew clang version 23.1.3`) and `built_from` (the SHA-256 of each source). **The generator now refuses** a stale module or one whose bytes no longer match its own record, and `--check` verifies each module against its record. `wasm` (Sound Map only) is kept for older readers; `format` stays 1 (additive). Root files `meter_lab.html` and `lab-data.json` appear in `files` without the `preview/` prefix; if your reader assumes the prefix, tell us.
- **Loading from the folder:** every module script carries its WebAssembly bytes inside the file (`b64`), so no fetch and no file read outside the page; your `allow-scripts` frame is enough.
- **Not in this drop:** the `tau-lab-set` message handler (O007/Q-031). We proposed its shape in 009; you have not confirmed it, so it is not built. Until then the page shows no live preset preview from the host.

## A010/2 · The name sidecar is listed (A006/R-024 follow-up: done)
`tau-compat.json` (and `docs/schemas/tau-compat.schema.json`) now list `tau-names.bin` and `tau-names.json` in every package's layout: role `generated`, `required` false, no data slot, formats **`tau-names`** (version 1, read from the firmware's own check) and **`tau-names-manifest`**. **The schema's format-name enum has two new values: if you validate our manifest with a strict copy of the schema, update it.** `check-card`: damaged magic, a newer version, a damaged header or a manifest that is not a sidecar manifest is an error; a sidecar bound to another build of the index is only a warning (the firmware ignores it); none at all is fine. A release zip that ships either file is refused when we build the manifest (it would overwrite the user's). The rehearsal manifest in `docs/interop/rehearsal-v0.7.0/` is a pinned older file and does not list them.
